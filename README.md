# EvenBetterFastSim: The reliable secsgem tool
---------------------------------------------------------
EvenBetterFastSim is a desktop utility for emulating the SEMI SECS/GEM communication protocol

## Features
----------
- HSMS communication with message logging
- Simulate workflows with multiple responses to messages
- Create and define equipment events, reports and varibles (S6F11)
- Simulate multiple instances at the same time, all communicating with each other

## Build and Debugging
